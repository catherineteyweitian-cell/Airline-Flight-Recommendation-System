## Project Overview
A Java-based Airline Flight Recommendation System developed collaboratively with team members, 
using graph data structures, adjacency lists, and BFS to manage flight networks and compare routes based on time and price.


## Features
- Represent airline flights using graph structures
- Add and manage flight connections
- Search for flight routes
- Apply graph and algorithm concepts to analyze flight connections

## Files
- `Graph.java` - Implements the graph structure and manages the flight connections.
- `Algorithm.java` - Contains the algorithms used to process and analyze the graph.
- `main.java` - Contains the main program used to run and test the system.

## Technologies Used
- Java
- Graph Data Structure
- Algorithms

## How to Run
1. Clone this repository.
2. Open the project in a Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.
3. Compile the Java files.
4. Run `main.java` to start the program.
